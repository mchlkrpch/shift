# Модуль ленты и Space-фронтенд

Запуск фронтенда

```
git clone https://github.com/mchlkrpch/shift.git
cd shift/shiftFront
npm install
npm run dev
```

Локально запустится приложение. 

> Внимание! Не выкладывайте в общий доступ никакой конфиденциальной информации, содержимое графа видно всем и используются как публичные заметки, которые могут повторять другие участники

> Внимание! Фронтенд делался на добровольной основе `ради вайба` и ведения заметок для себя на некоммерческой основе в оставшееся от труда времени, если вы заметите какой-то баг, автор будет благодарен за комментарий что вышло из строя.

> Внимание! Стоит помнить, что целью фронтенда является запись учебной информации, вся другая информация может быть удалена

Авторизироваться можно через `google account`. В профиле можно указать декоративную информацию о себе. На странице графов можно посмотреть пользовательские конспекты.

![img](./shiftFront/public/profile.png)

Чтобы создать граф перейдите в `/profile` и нажмите `create`. У вас откроется новый граф, где вы сможете печатать заметку. Чтобы сохранить конспект нажмите `ctrl+s`. Чтобы указать связь-пререквизит - нажмите `/` и вы увидите карты, на которые можно сослаться.
Чтобы посмотреть, как будет выглядеть карта нажмите `ctrl+q`. Редактор поддерживает katex, код и простой markdown.
![img](./shiftFront/public/links.png)

Если хочется редактировать заметку с друзьями - их можно добавить через collaborators-menu, открывающееся в левом верхнем углу.
![img](./shiftFront/public/editor.png)

По созданному графу можно запустить повторение.
![img](./shiftFront/public/feed.png)


Есть возможность парсить страницы/статьи в web по ссылки. Для этого нужно ввести в текстовый блок только ссылку и нажать alt+shift+enter.
![img](./shiftFront/public/parse.png)

> Если у вас есть свой api к нейросети

вы можете выделить слово в заметке и нажать `alt` - эти слова попадут в промт нейросети а под словами появится всплывающее окно

![img](./shiftFront/public/ai.png)

После нажатия `ctrl+enter` содержимое отправиться в нейросеть которая напишет ответ. Ответ сразу же можно перевести в режим редактирования по нажатию `ctrl+q`
